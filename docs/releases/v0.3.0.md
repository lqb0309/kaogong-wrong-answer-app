# v0.3.0 · Tauri 桌面版与完整复习工作流

发布日期：2026-10-17。

## 本次更新

- Tauri 完整桌面界面，复用全部学习业务，使用 macOS 系统 WebView；不含 Electron/Chromium。内置 Node.js 24 服务，使用者无需另装运行环境。
- 粉笔按日期导入、公共资料与子题、可靠原始解析和图表/公式缓存；题目先落库，再后台生成中文标签与复盘，提供任务暂停、继续和失败重试。
- 待确认与题库详情采用可调阅读分栏，文字题与图片均可查看；错误与超时按不同维度筛选，资料分析按整组预算评价。
- 复习中心统一选题与题量/时间预算、计时与答题回填；支持题目卷、解析卷与连续阅读页，公共材料成组排版，避免题解错配与重复输出。
- 每日计划结合学习记录、反馈和调休日历；AI 输出增加结构与截断校验，失败时保留原计划。知识卡片接入 FSRS 复习调度。
- DeepSeek 模型清单支持手填与安全错误反馈，适配 V4 推理预算；系统钥匙串与带认证加密保存凭据。
- 提供一次性 Electron 数据迁移与可恢复的本机安装工具，不自动覆盖原题库和 Obsidian Vault。

- `SHA256SUMS.txt`：安装资源的 SHA-256 校验值。
- GitHub 自动生成的 Source code：对应版本源码，不是可直接运行的安装包。

此包与本机已安装的 0.3.0 应用来自同一构建。安装资源不包含个人题库、笔记、粉笔会话或任何模型/插件密钥。现有用户升级前请备份；Electron 与 Tauri 分别存储数据，不能直接混用密文。迁移说明见仓库 `tauri-app/README.md`。
