# 技术改进与 Tauri 验证记录

日期：2026-10-15。两条路线均在开发工作区实施，未替换正式安装版、未迁移正式题库/Vault、未提交或上传 GitHub。已有工作区改动保留。

## 路线一：完善 Electron 正式技术路线

| 范围 | 已实现 | 边界 |
| --- | --- | --- |
| 依赖维护 | Electron 44.7.2、SQLite/Sharp/KaTeX 与构建链更新；Node 最低 22.12，CI Node 24 | 本机 macOS 验证；Windows/Linux 需另验 |
| 粉笔后台分析 | SQLite 持久队列；先抓取保存再分析；串行消费；暂停/继续/失败重试；顶部任务入口 | 暂停不撤回当前付费请求，不重试已入库题目 |
| 数据完整性 | 保留来源快照；导入中间状态隔离；字段/答案/报告汇总校验；失败不让半成品进入分析 | 网络响应适配只接受已验证的规范格式；真实未知接口仍走 DOM，不能宣称已替换为稳定官方 API |
| AI 可靠性 | Zod 结构校验、截断拒绝、有限重试、计划原值保护；合成质量评估入口 | 没有运行付费模型评估；结构有效不保证数学推理正确 |
| 日历与任务 | 2026 离线核验日历与公开日历缓存；补班按工作日；未知年份保守回退；一句话更正仍生效 | 不假设未公布年份的假期；不增加繁琐表单 |
| 卡片复习 | FSRS 四档真实回忆；保存状态与调度日志；历史记录保留 | 旧数据不伪造 FSRS 记忆参数；仅阅读不等于记住 |
| 复习导出 | 按题量/预计分钟选题；默认共同资料成组；题目、解析、长页；阅读与独立测试分开 | 分钟是估计而非硬性单题计时；手选可自行改变组合 |
| 资料组效率 | 完整组原始正确率、总用时、参考预算；缺失时间不判超时；保留原始难度系数 | 不猜测难度系数刻度；旧记录没有完整汇总时不补造；尚未按个人长期速度校准 |
| 阅读布局 | 待确认/详情可拖动分栏，支持键盘与比例记忆；小窗口可读完 | 长内容仍需区域内滚动，不以缩小文字强行塞进一屏 |

“反复错误先总结错因”已加入复习提示；自动生成专门的错因卡片尚未实现，不能算作已交付功能。暂不引入 Redis、后台服务、复杂向量库或全量 Tauri 重写。

## 路线二：Tauri 独立技术验证

独立应用、会话与 SQLite；复用主项目报告读取器；限制远程页面可调用命令；不读取正式凭据或执行 AI。

真实报告：15 题资料分析、73 张图片，其中 71 张为解析公式。发现原始解析公式标记被当成纯文本，已修正为原位图片，支持放大。原生长页 PDF 在临时验证库副本成功生成；图表或公式加载失败时停止导出，不猜测补齐。

尚未满足正式替换条件：离线缓存、全题型兼容、批量同步、完整学习功能迁移、系统 A4 分页人工验收、跨平台与签名公证。维持 Electron 正式路线，Tauri 继续独立验证，不把最小样例包大小当作完整迁移收益。

## 验证结果

- 主项目类型检查、生产构建；84 项离线测试（包括队列暂停恢复、FSRS、AI 截断、调休、来源字段、复习成组和 Tauri 公式渲染）。
- Electron 实际页面解析：6 类报告场景，包括混合对错、旧版、缺失答案、图片选项与不完整报告。
- 实际 SQLite/Sharp/PDF 导出：固定 20 题，题目与答案解析相互对应，长页离线资源、取消、重复操作和阅读/掌握区分通过。
- 隔离 UI：1024×768、1440×900、1920×1080 检查待确认、详情、分栏、设置和复习时间预算；无整页/横向溢出，长解析可以滚到结尾。
- Tauri：4 项 Rust 校验测试；真实报告副本的原生 UI/图片加载/长页 PDF 集成测试。
- 依赖审计：本次升级后运行时依赖 0 项已知告警；全依赖树仍有 8 项中等级开发工具链告警，无高/严重等级。不是安全保证，也没有用强制降级来清空数字。
- 未运行任何付费 AI 测试，不代表已对所有模型生成质量作出保证。
