# Tauri 桌面版（本机安装 0.3.0）

复用现有 React 页面、100 个业务调用和学习规则；Tauri/Rust 接管系统 WebView、窗口、文件选择、剪贴板、密钥保存与 PDF。2026-10-17 已按用户要求安装 0.3.0 至本机应用程序，显示名称为“小乖的考公错题屋”。以下验收记录保留各阶段的真实范围；本机安装完成不等同于全部功能已经真实场景验收或可跨电脑公开发行。

## 本机安装与恢复

- 正式启动入口：`/Applications/小乖的考公错题屋.app`；`~/Applications/` 同名入口链接到同一个新版，避免误开 Electron 旧版。
- 应用标识继续使用 `com.deca.wrong-answer.tauri`，保留已有题库、钥匙串凭据及用户配置。安装时核对 155 道已入库、11 道待确认，数据库完整性正常，模型密钥、图床 Token、图片目录及 Obsidian 配置均未改变。
- 用户在迁移后已将 Obsidian 路径改回原有 Vault；当前配置以用户选择为准，不会因安装恢复到迁移副本。
- 安装工具默认将旧应用与数据库快照保存至数据目录的 `installation-backups/`。旧包以 `.app.saved` 保留，恢复时应先退出新版，再按 `installation-report.json` 核对路径；不要用数据库旧快照直接覆盖新增记录。备份是否仍保留，以使用者后续清理操作为准。
- 后续本机安装可在关闭新旧程序后执行 `node scripts/install-tauri-macos.cjs /绝对路径/小乖的考公错题屋.app`。工具先检查签名与应用标识，备份数据库并暂存新包，再可恢复地替换应用；失败回滚，不改写 Vault 或学习记录。
- 当前是本机临时签名，不是 Apple 公证发行包。已确认安装位置的原生主进程与内置业务服务均启动；本轮界面检查受操作工具旧应用标识缓存影响，未宣称安装后所有页面均已视觉验收。

本机后续按用户授权完成旧版清理：核对文件副本后移走旧 Electron、验证版存储、安装/迁移备份与重复 Vault，修正笔记和归纳回执中的旧路径。现用数据库、图片目录、原 Vault 及新版常规启动备份保留。清理记录和废纸篓恢复材料只保存在本机，不随源码或 Release 上传。`migrated-data/` 名称不表示备份，其中仍可能存放正在使用的图片，不能直接删除整个目录。

## 技术边界

- 不包含或启动 Electron/Chromium；界面使用 macOS WKWebView。
- 为保持业务功能一致，随应用打包独立 Node.js 24 服务及 8 个直接业务依赖，通过私有标准输入/输出通信，不开本地 HTTP 端口。使用者不必另装 Node。
- 不是纯 Rust 重写，包大小和内存不能套用之前 10 MB 最小验证版的数据。
- 当前 macOS 包使用本机架构的 Node，约 200 MiB；仅做本机临时签名并校验完整性，未做 Apple 公证，不作为跨电脑公开发行包。尚未实测内存和耗电优势。
- 业务命令只开放给本地主窗口。粉笔及排版窗口不具备题库、文件、密钥命令权限；粉笔页面读取由原生 WebView API 完成，不向远程网页开放服务。
- 系统钥匙串保存独立随机密钥，业务凭据使用带认证加密；不把 Electron 密文当作明文，不降级为 base64 保存。

## 数据隔离

应用标识：`com.deca.wrong-answer.tauri`。

数据目录：`~/Library/Application Support/com.deca.wrong-answer.tauri/`。数据库 `data.db`，截图和笔记默认保存在此目录的 `local/`，不默认使用正式版的 `~/考公错题`；Obsidian 配置初始为空。

不会自动复制 Electron 的正式数据库、密钥、Vault 或粉笔会话，也不改写原 `tauri-lab` 验证库。正式数据迁移应先生成副本、去除旧格式密钥并核对图片路径，另行验收后执行。

## 构建

需要 Node.js 24 LTS、Rust 稳定版、macOS 原生开发工具。先在仓库根目录安装原项目依赖，再运行：

```bash
cd tauri-app
npm ci --ignore-scripts
npm run prepare:runtime
npm run typecheck
npm run test:rust
npm run build
```

`service/package-lock.json` 固定业务依赖；Node 原生模块只在 `runtime/` 内编译，不重建 Electron 的 SQLite。打包会包含自己的 Node，安装者无需配置运行环境。

产物：`src-tauri/target/release/bundle/macos/小乖的考公错题屋.app`。若开发者自定义 `CARGO_TARGET_DIR`，产物跟随该目录。

## 无费用隔离验收

```bash
# 仓库根目录，执行真实共享业务服务，不调用模型
node scripts/tauri-service-test.cjs
node --test tests/tauri-migration.test.cjs

# 生成全新的 /private/tmp 合成题库，再以 debug 构建运行原生验收
node scripts/tauri-full-fixture.cjs /private/tmp/your-new-tauri-test
WRONG_ANSWER_TAURI_FULL_TEST=/private/tmp/your-new-tauri-test ./tauri-app/src-tauri/target/debug/wrong-answer-tauri-desktop
```

自动测试仅在 debug 构建和 `/private/tmp` 独立目录下启用，release 不接受此变量。测试使用合成题库、测试密钥、隐藏窗口，关闭自动 AI、正式 Vault 写入与系统文件选择；不会读剪贴板真实图片来造测试数据。不要把生成数据库、报告、模型密钥、账号会话或打包运行时提交到仓库。

## 用户授权的数据迁移（2026-10-17，安装前历史）

已将正式 Electron 数据以独立副本方式迁入 Tauri，并保留 Tauri 原有 11 道待确认题。迁移后为 155 道已入库、11 道待确认、23 组资料、24 天计划、8 份复习清单、16 份粉笔学习记录；实际可读知识卡片 76 张、每日笔记 32 篇。初始文件扫描额外数到 1 份包含 `type: knowledge_card` 示例的 PRD，并非卡片遗失，原版与新版实际识别数均为 76。

`scripts/migrate-electron-data.cjs` 是需关闭新旧两个版本后执行的一次性工具，不会自动运行。旧版数据库先做包括 WAL 的私有快照，只在快照上恢复和兼容结构；新版切换前备份其原数据库与本地文件。保留旧版额外备注字段，并逐字段核对原记录、逐文件校验副本、检查外键及数据库完整性。路径同步改写覆盖公共资料、解析中的图片、Markdown 与历史导出清单。遇到异号同题时中止，不静默丢弃关联；拒绝复制到源目录内部以及再次覆盖已经迁移的题库。

正式切换的恢复材料保存在 Tauri 数据目录的 `migration-backups/electron-ZlPOTb/`，包括 `electron-before.db`、`tauri-before.db`、两边文件快照及 `migration-report.json`；不受普通 14 份启动备份轮换清理。新版工作副本位于 `migrated-data/electron-ZlPOTb/`，不会写回旧版原始图片与原 Obsidian Vault。新版后续笔记进入这个独立 Vault；旧目录和旧安装包均保留。

模型地址、模型名及加密密钥保留用户在 Tauri 中新配置的版本，未解密或显示密钥。旧 Electron 的 EasyImage、Obsidian 插件 Token 因加密格式不同不直接搬入；本地图片和直接写入 Markdown 不依赖这些可选 Token，需要图床上传或插件 API 时应重新配置。迁移测试及全量回归合计 104 项通过，已在真实 Tauri 窗口核对题库、公共资料、答案、复盘及卡片正文与关联错题。未在本轮重新安装或替换应用程序包。
